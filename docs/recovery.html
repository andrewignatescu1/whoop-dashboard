Recovery & HRV

Heart rate variability trajectories and autonomic nervous system readiness

Show code 
source("R/load_data.R")
library(patchwork)

HRV — the millisecond variation between heartbeats — is the closest non-invasive proxy for autonomic nervous system readiness. Higher HRV generally signals better recovery; lower HRV reflects accumulated stress, illness, or overtraining. WHOOP measures it each morning during a brief calibration window.

HRV vs. Resting Heart Rate

RHR and HRV should move in opposite directions under healthy adaptation — high HRV paired with low RHR is the ideal combination. The scatter below shows this inverse relationship in your data.

Show code 
cycles |>
  filter(!is.na(hrv), !is.na(rhr), rhr < 80) |>
  ggplot(aes(x = rhr, y = hrv, color = rec_zone)) +
  geom_point(alpha = 0.5, size = 1.8, shape = 16) +
  geom_smooth(method = "lm", se = TRUE, color = "#111", linewidth = 0.8,
              fill = "grey85", alpha = 0.5) +
  scale_color_manual(
    values = c(Green = "#1D9E75", Yellow = "#BA7517", Red = "#E24B4A"),
    name = "Recovery zone"
  ) +
  labs(
    title    = "HRV vs. resting heart rate",
    subtitle = "Linear trend with 95% confidence band",
    x = "Resting heart rate (bpm)", y = "HRV (ms)"
  ) +
  theme_whoop()

Rolling means: HRV, RHR, and Strain

This three-panel view (modeled after the NHANES multi-panel plots in the FDA textbook) shows 7-day rolling means for all three key recovery metrics simultaneously, making it easier to spot periods where all three converged or diverged.

Show code 
illness_bands <- tibble(
  xmin = as_date(c("2023-04-03", "2023-07-26")),
  xmax = as_date(c("2023-04-15", "2023-07-31"))
)

make_band <- function(p) {
  p + geom_rect(
    data = illness_bands,
    aes(xmin = xmin, xmax = xmax, ymin = -Inf, ymax = Inf),
    fill = "#E24B4A", alpha = 0.08, inherit.aes = FALSE
  ) +
  scale_x_date(date_breaks = "2 months", date_labels = "%b '%y") +
  theme_whoop() +
  labs(x = NULL)
}

p1 <- ggplot(cycles, aes(x = date, y = hrv_7)) +
  geom_line(color = "#3266ad", linewidth = 0.9, na.rm = TRUE) +
  labs(title = "HRV — 7-day rolling mean", y = "ms")

p2 <- ggplot(cycles, aes(x = date, y = rhr_7)) +
  geom_line(color = "#E24B4A", linewidth = 0.9, na.rm = TRUE) +
  labs(title = "Resting heart rate — 7-day rolling mean", y = "bpm")

p3 <- ggplot(cycles, aes(x = date, y = strain_7)) +
  geom_line(color = "#BA7517", linewidth = 0.9, na.rm = TRUE) +
  labs(title = "Day strain — 7-day rolling mean", y = "strain score")

make_band(p1) / make_band(p2) / make_band(p3)
Note

Red shaded regions mark two anomalous periods: early April 2023 (recovery crashed to 1% on consecutive days, HRV dropped sharply) and late July 2023 (RHR spiked to 120 bpm for several days — almost certainly illness or an injury event).
